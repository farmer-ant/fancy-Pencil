LibreDWG dwg2dxf, bundled with Fancy Pencil so .dwg files open without installing anything.

  Program:  dwg2dxf from GNU LibreDWG 0.14.8612 (commit f860b0fb76d5f8effb5a70769a3389cb1e0308c8)
  Built as: one stand-alone program for 64-bit Linux (x86-64), statically linked, stripped
  License:  GNU General Public License version 3 or later (see COPYING)
  Source:   https://github.com/LibreDWG/libredwg  (that commit)
            https://www.gnu.org/software/libredwg/

Fancy Pencil runs it as a separate program to turn a .dwg into a .dxf, which it then opens.
If ODA File Converter is installed, Fancy Pencil uses that instead (it also saves .dwg).

If you give Fancy Pencil to someone else, the GPL asks that you also give them (or offer them)
the LibreDWG source code for this program; the links above are where it comes from.
