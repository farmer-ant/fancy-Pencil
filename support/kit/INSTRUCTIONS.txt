FANCY PENCIL KIT
================

  install            Double-click it. That's all.
  INSTRUCTIONS.txt   This file.

"install" is a complete program with Fancy Pencil packed inside it. It opens a window with
the Fancy Pencil logo and walks you through:

  1. Where to put Fancy Pencil (a folder called "Fancy Pencil" in your home folder, unless you
     choose another), and whether to add it to the app menu and the desktop.
  2. ODA File Converter, for AutoCAD .dwg drawings: it opens the download in your web
     browser, you pick the downloaded file, and it is installed with everything else.
  3. Your password, once, so it can install what Fancy Pencil runs on (SBCL and Tk).
  4. It unpacks Fancy Pencil, prepares it, and offers to start it.

To update later, double-click a newer "install". Your settings, toolbars and drawings are kept.

It works on Ubuntu 22.04 and newer, Linux Mint 21 and newer, Debian 12, Fedora and openSUSE
(64-bit), and on Arch. Nothing else needs to be installed first.


IF DOUBLE-CLICKING DOESN'T START IT
-----------------------------------
The file has lost its "executable" mark on the way (downloads and some USB sticks do that):

    right-click "install" > Properties > turn on "Executable as Program"
    (older versions: Permissions tab > tick "Allow executing file as program")

then double-click it again. Or, in a terminal in this folder:   chmod +x install && ./install

The first time it runs it gives itself the Fancy Pencil logo in the file manager.
A record of what it did is kept in ~/.cache/fancypencil-install.log


ODA FILE CONVERTER BY HAND
--------------------------
  Download page:   https://www.opendesign.com/guestfiles/oda_file_converter

  Direct downloads (Linux, 64-bit):
    Ubuntu / Debian / Mint (.deb):
      https://www.opendesign.com/guestfiles/get?filename=ODAFileConverter_QT6_lnxX64_11dll.deb
    Fedora / openSUSE (.rpm):
      https://www.opendesign.com/guestfiles/get?filename=ODAFileConverter_QT6_lnxX64_11dll.rpm
    Any other Linux (AppImage):
      https://www.opendesign.com/guestfiles/get?filename=ODAFileConverter_QT6_lnxX64_11dll.AppImage
  (If a direct link stops working, ODA has a newer version - use the download page.)

  Then double-click "install" again and choose "I have downloaded it", or in a terminal:
    .deb       sudo apt install ./ODAFileConverter_*.deb
    .rpm       sudo dnf install ./ODAFileConverter_*.rpm
    AppImage   mkdir -p ~/.local/bin && cp ODAFileConverter_*.AppImage ~/.local/bin/ODAFileConverter
               chmod +x ~/.local/bin/ODAFileConverter


MOVING YOUR SETTINGS TO ANOTHER COMPUTER
----------------------------------------
Your preferences, recent files, command aliases and toolbars are in ~/.config/fancypencil
(a hidden folder in your home folder). Copy that folder to the other computer to keep them.


IF FANCY PENCIL WON'T START
---------------------------
Run it from a terminal (cd into the fancypencil folder, then ./fancypencil) to see any message.
When started from the app menu, messages go to ~/.cache/fancypencil.log
If it is stuck:   pkill -f fancypencil
