FANCY PENCIL KIT
================

  Install Fancy Pencil.deb   Double-click it.
  INSTRUCTIONS.txt           This file.

Double-clicking "Install Fancy Pencil.deb" opens your computer's own software installer
(App Center on Ubuntu, Software Manager / Package Installer on Linux Mint, Software Install on
Debian). It shows Fancy Pencil with its logo - click Install and enter your password.
It installs SBCL and Tk (what Fancy Pencil runs on) along with it.

Then start Fancy Pencil from the app menu.

To update, double-click a newer "Install Fancy Pencil.deb" the same way. Your settings,
toolbars and drawings are kept.

If double-clicking opens it in the wrong program: right-click it > Open With > App Center
(or "Software Install", or "Package Installer"). Or, in a terminal in this folder:
    sudo apt install "./Install Fancy Pencil.deb"

To remove Fancy Pencil:   sudo apt remove fancypencil


OPENING DWG FILES - ODA FILE CONVERTER
--------------------------------------
Fancy Pencil opens and saves AutoCAD .dwg drawings through the free ODA File Converter.
After installing Fancy Pencil, open  "Get ODA File Converter"  from the app menu (or, in Fancy
Pencil, Help > Get ODA File Converter). Click "Download .deb", then "Install the downloaded
file..." and pick it.

  Download page:   https://www.opendesign.com/guestfiles/oda_file_converter
  Direct download (Ubuntu / Debian / Mint):
    https://www.opendesign.com/guestfiles/get?filename=ODAFileConverter_QT6_lnxX64_11dll.deb
  (If the direct link stops working, ODA has a newer version - use the download page.)
  By hand:   sudo apt install ./ODAFileConverter_*.deb


MOVING YOUR SETTINGS TO ANOTHER COMPUTER
----------------------------------------
Your preferences, recent files, command aliases and toolbars are in ~/.config/fancypencil
(a hidden folder in your home folder). Copy that folder to the other computer to keep them.


IF FANCY PENCIL WON'T START
---------------------------
In a terminal type  fancypencil  to see any message.
When started from the app menu, messages go to ~/.cache/fancypencil.log
If it is stuck:   pkill -f fancypencil
